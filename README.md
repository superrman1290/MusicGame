# MusicGame

A four-lane rhythm battle game and chart editor. The production rewrite uses
Phaser, TypeScript, Vite, Express, Zod, and Vitest.

## Prototype baseline

The original standalone prototypes are preserved in `prototypes/`:

- `note-chart-editor.html`: waveform-based chart editor prototype.
- `rhythm-battle-prototype.html`: rhythm battle prototype.

These files are reference implementations. New development belongs in the
workspace applications and shared packages added in later stages.
